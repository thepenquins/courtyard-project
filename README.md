# Godot Template Project

Базовый Godot-проект.

Включается в себя:
- Автоматическое присвоение версии при сборке
- Движок для текстовых историй Rewind Story Engine
- Интеграцию Steam
- Интеграцию FMOD
- Шейдер пикселизации
- Базовые настройки
- Класс профиля
- Класс сохранения
- Асинхронный загрузчик уровней
